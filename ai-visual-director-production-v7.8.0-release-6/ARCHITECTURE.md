# V7.8.0 Release 6 Architecture

## Control plane

Routing Contract → verified or portable rule selection → Project Contract → artifact execution → actual-output extraction → deterministic validation → semantic/media/human review → package status.

## Generation plane

`NANO_BANANA_PRO` owns still prompts. `GEMINI_OMNI_FLASH` owns text-to-video, image-to-video, reference-to-video, and conversational video-edit prompts. The skill is prompt-only.

## Cross-mode parity

All four modes use the same control skeleton: intent, references, locks, prompt family, acceptance, failure, one-variable repair, fallback, evidence ceiling. Each mode adds its own craft fields and validators.

## Handoff plane

Post-production, compositing, exact text/UI, audio, captions, accessibility, and delivery are platform-neutral specifications. An advanced compositor is required when tracking, roto, perspective, reflections, or integration exceed a simple editor.

## Evidence plane

Planning, deterministic validation, semantic review, media inspection, human review, and release proof are independent. No layer may promote another without version-bound evidence.
