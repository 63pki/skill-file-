# Multilingual Audience Overlay

Load for `MULTILINGUAL` with the Localization production owner.

- Register language, locale, script, direction, proficiency, cultural context, and approved reviewer.
- Preserve claims and intent while adapting idiom, reading speed, line breaks, captions, voice, and layout expansion.
- Distinguish translation, transcreation, transliteration, dubbing, subtitling, and accessibility captions.
- Never claim native review from machine translation or creator self-check.
- Required artifact: locale review matrix with source copy, approved adaptation, timing/layout checks, reviewer, and unresolved issues.
