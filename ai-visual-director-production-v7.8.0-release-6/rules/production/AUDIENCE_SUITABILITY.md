# Audience Suitability — Runtime Owner

Load this owner whenever the Routing Contract contains an audience trigger.

1. Record audience type, age/expertise range, language, accessibility, vulnerability, and confirmed destination when relevant.
2. Adapt vocabulary, pacing, intensity, captions, contrast, sound, manipulation risk, and comprehension checks to the declared audience.
3. Creator/model review is preflight only. Never convert it into child, client, expert, accessibility, or representative-audience evidence.
4. An audience-comprehension claim requires a real, version-bound human-review record. Otherwise label it `NOT_RUN` or `NOT_PROVEN`.
5. Unknown audience triggers block verified routing rather than silently omitting this owner.
