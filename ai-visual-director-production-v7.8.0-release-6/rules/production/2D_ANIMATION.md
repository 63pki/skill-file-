# Mode B — Animation Owner

Required: animation method, character/world bible, asset IDs, expression/state set, environment and prop locks, timing/pose plan, world rule, durable resolution, Nano Banana Pro references, Omni Flash motion prompts, audio route, neutral post handoff, accessibility and inspection.

For each moving shot define intention, key pose path, action, deformation, contact, camera, environmental motion, audio, endpoint, acceptance, one-variable repair and fallback. Narration overflow or overloaded shots block motion. Test the hardest identity/performance/contact problem before full production.
