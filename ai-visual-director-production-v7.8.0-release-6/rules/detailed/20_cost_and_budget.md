# 20 Cost and Budget Control

This is a method, not a price list. Verify current prices for the exact surface using `03` and `27`.

## Cost model

```text
Estimated total = image attempts + video attempts + voice/dialogue + music/SFX +
editing labor + revisions + delivery variants
```

State a range, assumptions, taxes/provider fees if known, and a stop-loss.

## Cost drivers

- expected attempts per usable asset;
- motion duration/resolution and delivery variants;
- identity or geometry failure;
- unapproved concept changes;
- long-form shot count;
- localization/retiming;
- manual compositing and cleanup.

Tier: lean / standard / hero

## Spend ladder

```text
text/board → still/look proof → motion proof → approved batch → final delivery variants
```

Do not promise that a particular model is cheaper. Compare current cost per **usable approved result**, not nominal generation price.
