# 27 Evidence and Capability Registry

Use this record for volatile specifications and non-obvious empirical claims.

```text
Evidence ID:
Claim/capability:
Tool and exact surface:
Plan/tier/region:
Value or observed behavior:
Source URL/location:
Source class:
Verified date:
Recheck/expiry date:
Confidence label:
Scope/exceptions:
Files/decisions using it:
Fallback if stale or unavailable:
```

## Rules

- One row per claim; do not bundle unrelated capabilities.
- Official broad model marketing is not proof of a surface-specific control.
- Provider documentation governs that provider only.
- Creator observations describe behavior, not guaranteed limits or rights.
- Remove expired current recommendations; archive them as historical.
- Never copy secret keys, private data, or restricted material into this registry.
