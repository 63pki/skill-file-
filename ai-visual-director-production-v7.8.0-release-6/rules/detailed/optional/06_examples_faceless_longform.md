# Optional Examples — Faceless and Long-Form

## History documentary chapter

```text
Question: why did one overlooked infrastructure choice reshape the city?
Flow: artifact/evidence hook → context map → human consequence → competing explanation → sourced resolution.
Visual mix: exact maps/design graphics, disclosed reconstructions, object/location details, archival material with rights.
Avoid: fake quotations, invented footage, generic endless cinematic B-roll.
```

## Science explainer

```text
Promise: understand one scale relationship by the end of the chapter.
Visuals: controlled diagram, physical analogy, macro evidence, scale comparison, recap frame.
Mode C owns exact labels/data; generated visuals may illustrate but never validate facts.
```

## Philosophy/motivation

```text
Replace lions, mountains, and glowing silhouettes with one recognizable behavior moment.
Structure: relatable evidence → reframe → one concrete action → reflective close.
Do not promise life transformation or diagnose the viewer.
```

## Packaging

Create title, cover, and opening that add different information while promising the same honest payoff. Do not invent CTR/retention predictions; test after publication and record the actual sample/context.
