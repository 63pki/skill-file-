# Optional Examples — Ads and Products

Hypothetical plans only. Adapt claims, references, mode, platform, and current tool controls.

## Luxury fragrance — sensory restraint

```text
Concept: the scent is suggested through temperature, texture, and space—not literal ingredient explosions.
Board: black-field macro → condensation/light caress → hand/object relationship → restrained packshot.
Look: controlled hard rim plus negative fill; glass refraction; one amber accent; minimal atmosphere.
Sound: cap friction, glass placement, low room tone, sparse score resolve.
Risk: warped bottle/label; keep product anchored and add typography in post.
```

## SaaS workflow ad — mechanism, not fake UI

```text
Concept: scattered work collapses into one clear flow.
Board: evidence of overload → clean motion-graphic metaphor → controlled real UI capture/design → outcome → CTA.
Mode: C with optional human Mode-A hook.
Rule: exact UI, charts, labels, and numbers are controlled post elements—not generated pseudo-interfaces.
```

## UGC skincare — honest ritual

```text
Concept: one believable routine improvement, not a medical transformation.
Opening: specific frustration visible in the routine.
Look: phone-camera perspective, available light, imperfect framing, natural skin texture.
Motion: one application action per shot; product geometry anchored.
Claims: use approved cosmetic wording; no cure, guaranteed result, or fabricated testimonial.
```

## Restaurant food — memory and texture

```text
Board: craving evidence → ingredient/cooking macro → steam/sauce action → human reaction → location/offer.
Look: warm side light, accurate food color, tactile texture, realistic steam direction.
Sound: sizzle, knife/plate, pour, room bed; music supports rather than replacing food sound.
```

## Real estate — spatial understanding

```text
Board: exterior orientation → threshold → best room wide → detail/lifestyle insert → view/neighborhood → CTA.
Directing: preserve geography and screen direction; use wide perspective carefully; architecture must stay stable.
Disclosure: clearly label synthetic staging or reconstruction when it could be mistaken for the real property.
```

## Fashion editorial — wardrobe continuity

```text
Board: identity image → fabric detail → walk/action → reaction/turn → final silhouette.
Anchor: face, coat/outfit, material, and color as separate approved invariants.
Motion: matched tracking or locked performance; prioritize fabric physics and readable body contact.
```

## Fitness/wellness — behavior, not body guarantee

```text
Concept: a repeatable ritual replaces heroic transformation imagery.
Visuals: shoes by bed, realistic training, water/meal preparation, recovery detail.
Claims: no guaranteed body/health outcome; show process and approved support language.
```
