# Optional Examples — Film, Animation, Motion Graphics, and Hybrid

## Cinematic short — unresolved object

```text
Concept: an ordinary room contains one object that implies an absent person.
Coverage: geography wide → object insert → character objective → obstacle evidence → reaction → unresolved exit image.
Continuity: world map, prop state, screen direction, time/light logic.
Sound: room tone and object detail carry tension before score enters.
```

## Two-character dialogue

```text
Board: establishing two-shot → speaker medium/close → listener reaction → relevant insert → changed two-shot.
Generate separate clean singles when identity control is fragile. Preserve eyeline and screen side.
Use native dialogue only for short visible lip-sync after a capability test; external dialogue is the fallback.
```

## 2D character short

```text
Style: limited palette, clean line, two-step cel shadow, readable silhouettes.
Board: setup pose → anticipation → action → reaction → held payoff.
Assets: character turnaround, expression row, hand/prop rules, two reusable background plates.
Suppress: photoreal shading, palette drift, extra character, line-weight change.
```

## Stylized 3D mascot product ad

```text
Keep mascot and real product as separately approved assets. The mascot may exaggerate; the product may not change geometry.
Composite with shared light direction, contact shadow, edge softness, and grade. Avoid protected studio shorthand.
```

## Motion-graphics explainer

```text
VO beat: "Invoices used to consume the afternoon."
Weak visual: the word INVOICES plus a generic document icon.
Directed visual: a clock drains into an expanding paper stack; one tap collapses the stack into a clean timeline.
Execution: image generator for optional illustration assets; editor for exact type, grid, UI, easing, and data.
```

## Hybrid live + generated effect

```text
Plan: clean plate → isolated generated effect → track points → matte/occlusion order → contact/reflection → edge/grain/blur match → final type.
Reject if perspective, light, or scale cannot be reconciled. State when a more capable compositor is required.
```
