# Optional Cinematic Look Library

Use inside **photoreal/cinema mode only**. Select one coherent family, then modify it for the actual story and brand. These are `[WORKFLOW HEURISTIC]` craft starting points, not camera/model guarantees.

## Conflict / reportage

```text
Observational 35mm perspective; controlled handheld response; available hard or smoke-diffused light;
muted earth/ash palette; imperfect framing; dust/haze only where physically motivated;
restrained contrast; no glossy studio symmetry.
```

## Intimate romantic drama

```text
Portrait-scale perspective; soft motivated window or low-sun light; warm highlight roll-off;
shallow but believable separation; amber/blush neutrals; restrained bloom; slow push or held frame;
textured skin, no beauty-filter wax.
```

## Science-fiction scale

```text
Wide perspective for geography; strong practical light logic; edge/rim separation; steel/cyan world with one warm accent;
volumetric atmosphere only in visible light paths; deliberate reveal movement; no random neon clutter.
```

## Street realism

```text
28–35mm observational perspective; mixed practical color temperatures; natural whites;
wet reflections or exhaust haze only when motivated; loose framing and human micro-corrections;
no fashion-studio polish.
```

## Noir / dread

```text
Selective focus; one hard motivated source; negative fill and large dark fields;
muted or near-monochrome palette with one sickly/cold accent; static hold or slow dread push;
readable silhouettes, not crushed incomprehension.
```

## Natural-history documentary

```text
Long-lens subject isolation or wide environmental scale; patient subject-led camera;
true-to-world color; soft overcast or low-sun rim; realistic atmospheric depth;
no artificial HDR halos or fantasy saturation.
```

## Historical drama

```text
Period-authentic production design; classical composition; candle/lamp/window light logic;
age-appropriate palette and material response; measured camera; explicit anachronism suppression;
validate factual reconstruction and disclose synthetic scenes when needed.
```

## Action thriller

```text
Readable geography; one dominant action phase per shot; directional hard light and practical bursts;
controlled handheld or matched tracking; motion blur consistent with speed; smoke/rain/sparks only when causal;
coverage for the reaction and consequence.
```

## Ethereal / contemplative

```text
Soft backlight and diffused wrap; lifted but not washed contrast; pale sky/gold palette;
slow drift or near-still composition; fine mist in light paths; generous negative space;
avoid generic floating-particle overload.
```

## Luxury / fashion

```text
Restrained palette; shaped studio key plus negative fill; controlled speculars; macro/detail coverage;
precise negative space; slow exact motion; physical metal/glass/fabric behavior;
no plastic shine, fake perfection, or unnecessary props.
```

## Use test

- Does the look express the concept, or merely announce a genre?
- Is every light/material/movement choice coherent?
- Can it remain consistent across the planned coverage?
- Does the token conflict with the approved reference or delivery format?
