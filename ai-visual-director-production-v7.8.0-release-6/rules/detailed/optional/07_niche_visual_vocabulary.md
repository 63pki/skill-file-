# Optional Niche Visual Vocabulary

This is visual-direction vocabulary—not a niche-ranking, monetization, or business-coaching system.

| Category | Avoid | Prefer |
|---|---|---|
| Finance | cash rain, rockets, fake dashboards | bills, calculator, budget notebook, ordinary tradeoffs, risk diagrams |
| Health/wellness | miracle glow, fake clinical authority | routines, sleep/water/food environments, calm evidence, realistic bodies |
| Productivity | generic clocks and “hustle” | open loops, tabs, calendars, unfinished objects, before/after systems |
| Education | dense slide walls | one visual mechanism, analogy, worked example, practice prompt |
| History | random sepia, careless costumes | artifacts, maps, architecture, period materials, disclosed reconstruction |
| Science/space | unsupported spectacle | scale comparisons, controlled diagrams, experiment details, source-backed labels |
| Technology/SaaS | fake holograms, pseudo-UI | real workflow friction, designed UI, product mechanism, human context |
| Luxury | gold clutter, arbitrary marble | restraint, material behavior, negative space, controlled reflections |
| Fashion/beauty | body/skin perfection | identity, fabric construction, editorial staging, natural texture |
| Food | flat overhead sameness | heat, steam, sauce, break/cut/pour, cultural context, human reaction |
| Travel | generic postcard montage | local routines, thresholds, transport, markets, textures, specific time of day |
| Real estate | distorted ultrawide fantasy | spatial geography, daylight logic, material detail, disclosed staging |
| Automotive | impossible physics, endless wet-road cliché | engineering details, contact, reflections, driver context, believable speed |
| Kids/family | fear bait, manipulative CTA | warm objective, readable character problem, playful escalation, safe resolve |
| True crime | gore and exploitation | timeline, documents, locations, respectful evidence, uncertainty labels |
| Sustainability | guilt-only disaster montage | visible system, repair/reuse, measurable claim, practical action, hopeful consequence |

Use this table to reject category clichés, then create concept territories specific to the actual brief.
