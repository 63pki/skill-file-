# Optional Hook Pattern Library

Use core `23_hooks_and_packaging.md` first. These are construction starters, not swipe-copy guarantees.

## Evidence-first

```text
Show the concrete consequence before explaining the cause.
"This [ordinary object] is costing/causing [specific consequence]."
```

## Contradiction

```text
Visible common behavior + one credible contradiction.
"The part everyone optimizes is not the part causing the delay."
```

## Result first, mechanism withheld

```text
Show the approved result, then open the mechanism question.
"This changed after we removed one step—not after adding another tool."
```

## Sensory transformation

```text
Begin with a texture/sound/material state that changes visibly.
No empty “watch this”; the action itself earns attention.
```

## Character objective and obstacle

```text
A character wants one clear thing; the obstacle is visible in frame one.
Works for narrative, animation, and product stories.
```

## Question with evidence

```text
Ask only after showing why the question matters.
"Why is this room colder when the system says it is off?"
```

## Open-loop story

```text
Start after the initiating event but before the consequence is understood.
Reveal context through evidence rather than generic “you won't believe what happened.”
```

## Hook test

- specific to this product/story?
- understood at delivery size and without sound?
- honest and paid off?
- free of generic secrecy/FOMO language?
- structurally different from the other options?
- safe for the audience and category?
