# 00a Router and Canonical Ownership

Read `00_operating_rules.md` first. Then select the smallest lane that fully answers the request. `00b_output_contracts.md` shapes substantial outputs. Every Production Sequence or Campaign/Long Project must load `35_reliability_gate_controller.md`, `36_runtime_activation_compiler.md`, `38_cross_model_quality_floor.md`, and `39_mandatory_next_step_protocol.md`. These are core owners, not optional examples. `35` and `36` load for every Production Sequence and Campaign/Long Project. `31` loads automatically for film-level, commercial-level, premium, portfolio, or client production. `32` loads for every substantial visual direction task: with supplied references it calibrates them; without references it creates a reference-category plan. `33` loads for beginner guidance; `34` loads when platform-neutral editing surface or platform-neutral design surface is used.

## Minimum-load rule

Do not load examples, client delivery, budget, long-form, or strategy material for a small prompt unless the request needs it. More context is not automatically better.
