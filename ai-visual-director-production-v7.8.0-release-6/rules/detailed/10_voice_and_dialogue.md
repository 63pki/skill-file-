# 10 Voice and Dialogue

## Choose the dialogue path

| Need | Default path |
|---|---|
| Long narration, brand-critical wording, localization, revision control | external voice generation + editor |
| Short visible line with intentional lip-sync and verified support | native video dialogue may be tested |
| No mouth sync needed | off-camera VO |
| Character series | external voice token; lip-sync only where necessary |

Native dialogue is an option, not a violation of the external-VO default.

## Script-for-the-ear rules

- one idea per sentence;
- concrete words before abstract claims;
- punctuation as performance direction;
- write pronunciations for brands, names, numbers, and acronyms;
- read aloud and time the copy;
- do not fabricate testimonials or outcomes.

## Long-form chunking

Verify the current model’s limits, then split at paragraphs or scene boundaries. Keep one approved voice and settings token, number chunks, retain handles at seams, and compare pitch/energy across every join. Never claim seamlessness without listening.

## Native-dialogue test card

```text
Visible speaker:
Exact short line:
Why native lip-sync is required:
Current surface support verified? [evidence ID]
Fallback: [external line / reaction shot / off-camera VO]
Acceptance: intelligible words, correct speaker, acceptable mouth sync, no subtitles/extra speech
```

## Dialogue timing verification

Before locking the storyboard, read or record every line and compare actual delivery with available screen time.

```text
Line ID:
Speaker:
Words:
Read-aloud duration:
Reaction/hold allowance:
Total required time:
Current shot/sequence duration:
Verdict: FITS / REWRITE / SPLIT / MOVE OFF-CAMERA
```

Rules:

1. Include pauses for comprehension, reaction, breath, and edit transitions.
2. Do not fit two full dialogue exchanges into a shot that only holds one readable action.
3. For children or instructional work, allow additional comprehension time rather than filling the runtime with speech.
4. Shorten language before speeding delivery unnaturally.
5. Move non-essential explanation to narration, another shot, or remove it.
6. Lock final VO timing before final motion generation when VO controls the edit.

## Mechanical timing worksheet — mandatory when speech controls the board

Calculate before board approval:

```text
estimated seconds = word count ÷ assumed WPM × 60
required window = estimated seconds + performance pauses + comprehension holds
```

Provide line and total values. “Read it later” is not a PASS. Use the estimate for planning, then replace it with measured read-aloud/rendered duration before final motion lock. If the total required window exceeds the project runtime after essential silent beats, rewrite or remove copy before generating motion.
