# 02 Brief, Workflow, and Preflight

## Brief diagnosis

Collect only what changes production:

```text
Deliverable and duration:
Audience and viewing context:
Viewer feeling at start / end:
Viewer action:
Platform and orientation:
Mode or desired look:
Available references and ownership:
Must-show / must-not-show:
Claims and proof available:
Budget tier / deadline / approver:
```

If information is missing, separate **blockers** from **assumptions**. Proceed with assumptions when safe and reversible.

## Concept gate

Before prompts, define:

- one north-star sentence;
- 2–4 genuinely different concept territories;
- the category clichés to avoid;
- why the chosen territory belongs to this brand/story;
- start emotion, turn, and end emotion;
- the visible proof or story event—not just a claim.

A concept territory changes the metaphor, story mechanism, or visual world. A different lens or color grade is not a different concept.

## Production workflow

1. **Brief:** lock objective, action, claims, rights, and delivery context.
2. **Mode:** choose photoreal, stylized, motion graphics, or hybrid.
3. **References:** assign each file one role; reject weak/conflicting inputs.
4. **Board:** time the story and edit before generating.
5. **Anchors:** create/approve product, character, environment, or design frames.
6. **Motion:** select ref2video, text2video, or first/last-frame per shot.
7. **Sound:** decide native dialogue versus external VO; write SFX/music cue sheet.
8. **Post:** assemble, grade, type, caption, mix, and deliver.
9. **Review:** use actual evidence; repair one causal variable.
10. **Memory:** save approved tokens, failed attempts, and handoff state.

## Generation preflight

### Required blockers

- [ ] Safety, consent, rights, privacy, and claims intake passed (`21`).
- [ ] The user owns or can use every supplied brand/reference/voice asset.
- [ ] Mode and deliverable are declared.
- [ ] Current capability facts that affect feasibility are verified (`03`).
- [ ] Critical text/logo/disclosures have an editable post-production plan.

### Production readiness

- [ ] For film/commercial/premium work, the automatic excellence gates in `31` are active.
- [ ] When references exist or a quality bar is needed, `32` calibrated roles, compatibility, do-not-copy boundaries, and the north-star standard.
- [ ] When the user is a beginner, `33` operator profile and teaching layer are active without reducing the quality target.
- [ ] When platform-neutral editing surface/platform-neutral design surface is used, `34` owns executable assembly/design handoffs.
- [ ] At least two concept territories passed originality review; rejected directions were replaced.
- [ ] Narrative cause, decision, consequence, permanent resolution, and world/magic rules pass the story-logic gate in `31`.
- [ ] Recurring animated assets have explicit anatomy/movement schemas and true model-sheet prompts (`13`).
- [ ] Scenes are divided into feasible shots/generation clips (`09`).
- [ ] Dialogue read time plus reaction/comprehension allowance fits (`10`).
- [ ] Load-bearing frame counts/rates/durations/export values are verified or marked verify-in-app (`03`).
- [ ] The response makes no unconfirmed file/action claim and cannot self-modify during production (`00`).
- [ ] Chosen concept is distinguishable from category clichés and has a one-frame visual thesis, memory device, and sound identity.
- [ ] Storyboard has time, story function, visual, camera, and audio per shot.
- [ ] Identity-critical shots use approved references or an explicit exception.
- [ ] Prompt lint passes (`17`).
- [ ] Sound layers and edit ownership are clear.
- [ ] Budget stop-loss and approval gates exist when cost matters.

Do not turn this checklist into ritual for a single low-risk prompt. Apply only the relevant blockers and readiness checks.

## Approval gates

```text
G1 Brief/concept + originality → G2 look/anchor + mode craft → G3 motion proof + continuity → G4 rough cut + sound identity → G5 no-ship/final delivery
```

A failed gate returns one stage, not automatically to the beginning.
