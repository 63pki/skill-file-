# Portable Reference Profile

Use this profile when the host can read the required workflow text and produce structured output but cannot reliably run Python, retain files, calculate hashes, inject a cryptographically verified context, or execute package validators.

## Assurance boundary

Always report:

```text
Assurance: PORTABLE_REFERENCE · Deterministic runtime verification: NOT_AVAILABLE · Instruction compliance: NOT_VERIFIED · Media evidence: NOT_RUN
```

Portable Reference authorizes useful planning and prompt-library work. It does not authorize claims of cryptographic loading, deterministic validator success, generated media, inspection, audience review, release readiness, or cross-model compliance.

## Mandatory reading order

1. `SKILL.md`
2. `rules/CORE_CONTROLLER.md`
3. This profile
4. The selected production owner
5. The selected audience owner, when triggered
6. The selected generation adapters and pipeline
7. The project brief and Portable Execution Record

Load reference manuals only when a selected owner points to them. Historical files and development fixtures are never runtime authority.

## Script-free execution

1. **ROUTE:** select delivery mode, production mode, audience triggers, and tool owners.
2. **LOAD:** list every selected active file in the Portable Execution Record. Do not claim hash verification.
3. **CONTRACT:** compile the required artifacts, locks, timing, acceptance rules, repair actions, assumptions, and blockers in text or JSON.
4. **EXECUTE:** create only the authorized planning or prompt deliverables. Generation, inspection, and export remain unavailable unless the host actually performs them.
5. **SELF-CHECK:** check required sections, exact tool ownership, story timing, evidence labels, and prohibited claims. This is not deterministic validation.
6. **REPORT:** return the compact status line and Portable Execution Record. Mark unavailable validation and evidence honestly.

## Mode B rule

Mode B still requires Nano Banana Pro for character, environment, and keyframe prompt ownership; Gemini Omni Flash for moving-shot prompt ownership; the Nano-to-Gemini Omni Flash pipeline; and platform-neutral audio attachment after approved clips exist. platform-neutral design surface and platform-neutral editing surface never replace generation owners.

## Fail closed

Use `UNSUPPORTED_EXECUTION` rather than Portable Reference when the host cannot load the core files, cannot preserve the selected production owner, cannot produce structured output, or would be forced to conceal limitations.

## Proof boundary

A Portable Execution Record is a declared process record. It can make omissions visible, but it cannot prove private attention, complete reading, honesty, execution, media quality, or future compliance.
