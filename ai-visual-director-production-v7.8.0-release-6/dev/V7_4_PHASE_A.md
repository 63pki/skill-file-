# V7.4 Phase A — Architecture Correction

Phase A removes the bootstrap circularity with a minimal Routing Contract, then Verified Runtime loading, then full Project Contract compilation, then final contract binding. It adds `VERIFIED_RUNTIME` and honest `PORTABLE_ASSURANCE`. Strict verification remains fail-closed; portable work is PLAN-PASS capped and cannot claim cryptographic or deterministic execution. Product language is corrected to context availability and response linkage, not obedience proof.
