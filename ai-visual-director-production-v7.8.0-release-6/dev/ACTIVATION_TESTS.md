## V6.11 quality activation

Substantial visual direction activates the Visual Exploration Matrix and Signature Test. Principal recurring assets activate silhouette comparison. Time-based projects activate color scripting. Final quality review activates the weighted scorecard. If visual generation/inspection is available, Design requires actual processed evidence; otherwise status remains STYLE TEST REQUIRED.

Mode B cutout/rig/frame work activates the 2D production module. Supplied/generated media activates visual or audio inspection. platform-neutral design surface/platform-neutral editing surface activates one named surface adapter. Audience validation claims activate Human Review. File-capable Delivery activates Export Manifest and actual validated outputs.
