## Conflict resolutions

- Text-only planning vs media execution: planning is always available; execution is conditional on actual host capability.
- Design visual evidence vs unavailable vision: use STYLE TEST REQUIRED, never invented inspection.
- Automatic exports vs unavailable files: produce manifest/source only.
- Human checkpoint vs unavailable participants: status remains REQUIRED or authorized waiver; never positive evidence.
- Adapter specificity vs volatile UI: exact paths require date/surface evidence; otherwise operation-level fallback.
- Quality score vs safety/compliance: both must pass; neither compensates for the other.
- Production module vs core: runtime wins and logs the conflict.
