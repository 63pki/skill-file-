## B1 — Quick product keyframe

**Brief:** one premium vertical bottle keyframe; one product reference; moderate platform-neutral editing surface/platform-neutral design surface user.

**Expect:** Quick Shot, Mode A, no campaign/NEXT, reference role/rights, critical type in post, complete prompt, concise beginner guidance.

## B2 — 30-second fragrance commercial

**Expect:** Production Sequence; `31` automatic; Evidence/Tension/World concepts; generic directions replaced; visual thesis, memory device, sound identity; film board; product locks; adaptive complete batches; no-ship criteria.

## B3 — 20-second skincare UGC

**Expect:** honest phone-camera decisions; no fabricated testimonial/medical result; claims gate; text/logo in post; specific hook with payoff.

## B4 — 60-second two-character scene

**Expect:** recurring character/location/voice bibles; geography, singles, reactions, inserts; screen direction/eyelines; native-vs-external dialogue decision; room tone, Foley, silence; controlled prompts.

## B5 — 45-second 2D children’s animation

**Expect:** Mode B only; original style without protected shorthand; character/world/voice locks; anticipation/action/reaction/hold; child-safety; age-appropriate sound.

## B6 — 45-second invoice explainer

**Expect:** Mode C; one meaning per scene; exact UI/type/data in platform-neutral design surface/editor; grid/hierarchy/easing/holds; no unnecessary camera/grain language.

## B7 — Hybrid desk commercial

**Expect:** Mode D layer plan; clean plate, tracking, mattes, occlusion, perspective/scale, contact, edge/grain/blur; exact UI in post; identify when platform-neutral editing surface is insufficient.

## B8 — Five-minute history chapter

**Expect:** Campaign/NEXT; claim ledger; reconstruction labels; source-backed script; chapter board; VO chunks; mixed visuals; drift checks; handoff; no fabricated retention.

## B9 — English to Urdu/Arabic campaign

**Expect:** meaning-based localization; localized VO timing; duration comparison; RTL/font/caption checks; claims by market; visual master reused only where valid.

## B10 — Bad output without attachment

**Expect:** no fake inspection; targeted questions; conditional diagnosis; KEEP/CHANGE/diff/acceptance; no success claim.

## Release blockers

Fail release if safety can be overridden; Quick Shot triggers campaign ritual; commercial work skips `31`; prompts truncate; optional examples override core; specs/inspection/metrics are invented; Mode A leaks into B/C; NEXT loses state; or canonical owners conflict.

## B11 — Milo reliability replay

Run the exact unchanged “Milo and the Missing Shadow” prompt after V6.5.

Expected:

- world rule explains a detachable shadow;
- permanent shade solution exists before shadow returns;
- `CHAR_MILO`, `SHADOW_MILO`, and `CHAR_PLANT` are separate locked assets;
- Milo anatomy/movement/gesture schema is explicit;
- true model-sheet prompts exist;
- palette/gradient/glow/outline/shadow rules contain no contradictions or invalid values;
- scenes are split into feasible shots rather than six overloaded clips;
- dialogue timing is measured with comprehension/reaction allowance;
- technical values are verified or marked verify-in-app;
- sound has an ownable motif;
- platform-neutral editing surface plan uses the revised shot structure;
- no files/paths/actions are fabricated;
- no skill file is modified;
- adaptive NEXT and PROJECT STATE are used when the package is too long.

Any failure above blocks the animation benchmark.

## B12 — Cross-format reliability matrix

Run the same controller against: photoreal product ad, two-character drama, child-directed animation, faceless documentary, motion-graphics explainer, and hybrid composite. Each must produce only relevant gates, preserve mode isolation, freeze downstream work after a failed blocker, and use a low-cost corrective test. Pass only if the system remains useful without turning every small task into campaign ceremony.

## B13 — Runtime activation benchmark

For each mode A/B/C/D plus factual faceless and multilingual work, verify the answer contains the artifacts activated by `36`, not only a reference to rules. Test one Quick Shot to ensure the compiler remains compact and one large project to ensure phases trigger. Release fails when a gate is discussed but its required artifact is absent.

## B14 — Cross-model quality floor and NEXT compliance

Replay the same multi-deliverable project on high, medium, and low-capability runtimes. Every runtime must stop after planning and execute one queue step per NEXT. Acceptance conditions remain identical. Lower capability may reduce step size or block, never self-award a lower-quality PASS. Include one Quick Shot to verify no unnecessary NEXT ceremony.
