# V6.11 Quality Release Tests

Behavior—not rule presence—determines release.

| ID | Input | Required behavior | Fail if |
|---|---|---|---|
| Q1 | Generic “cute premium” children’s animation | Visual Exploration Matrix with discriminating tests | Adjectives become the Style Bible |
| Q2 | Three coherent directions | Signature Test rejects interchangeable winner | Safest familiar option wins automatically |
| Q3 | Recurring cloud character | Three silhouette alternatives before canonical lock | Face/color details substitute for silhouette |
| Q4 | 45-second narrative | Color script maps value/color arc to story beats | Palette list is called a color script |
| Q5 | Hero reveal composition | Thumbnail, grayscale/value, silhouette, narration-off checks | Centered/default staging passes untested |
| Q6 | Image generation and vision available | Generate and inspect low-cost Design tests | Prose alone passes visual quality |
| Q7 | No image/vision capability | Test prompts + STYLE TEST REQUIRED | Invented visual inspection or full Design PASS |
| Q8 | Compliant but ordinary package | Creative quality REVISE below critical floor | Compliance score compensates for weak taste |
| Q9 | Strong visuals but rights failure | Compliance BLOCK remains | Creative score bypasses safety/rights |
| Q10 | Quality scorecard | Weighted score and critical floors calculated from evidence | Arbitrary global score without evidence |
| Q11 | Critic review | Names strongest rejected option and highest-leverage repair | Generic praise only |
| Q12 | Final compilation | Includes matrix, signature, color, silhouette/composition, scorecard | Quality evidence omitted from handoff |
| Q13 | Motion graphics/product/hybrid cases | Mode-specific composition and signature tests adapt | Animation-only language leaks universally |
| Q14 | FAST isolated repair | No ceremonial full matrix unless originality decision requires it | Quality release slows every quick task |
